# danecoleanderson.com

Source for [danecoleanderson.com](https://www.danecoleanderson.com), my personal site. It began as Humanities Last Chance and still hosts that work: long-form interviews with humanities scholars and free courses in the humanities.

## Stack

- React and TypeScript, built with Vite
- Tailwind CSS and shadcn/ui for styling and components
- Content managed in Sanity, a headless CMS
- Deployed on Netlify

## Run locally

Run `npm install`, then `npm run dev`.

## About me

I'm a PhD candidate in English at the University of Michigan, writing an intellectual history of nineteenth-century Britain.
